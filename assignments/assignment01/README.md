## 4. Problem Set

### Problem 1: Monthly Budget Analyzer (Basic)

A student tracks monthly expenses under the following categories:
- Rent
- Food
- Transport
- Utilities

Write a Python program that:
1. Stores each expense in a variable
2. Calculates total monthly expense
3. Displays whether the student is **Within Budget** or **Over Budget**

**Budget Limit:** 60,000 PKR

**Concepts Tested:**
- Variables
- Arithmetic operations
- Simple conditional logic

---

### Problem 2: Electricity Bill Estimator (Intermediate)

Electricity charges are calculated as follows:
- Units ≤ 100 → Basic Rate
- Units 101–300 → Standard Rate
- Units above 300 → High Usage Rate

Write a program that:
1. Takes number of units as input
2. Determines the applicable rate category
3. Displays the billing category clearly

**Concepts Tested:**
- User input
- Multiple conditions (`if–elif–else`)
- Logical completeness

---

### Problem 3: Class Attendance Analysis (Intermediate)

Given a list representing attendance percentages of students:

`[72, 85, 90, 60, 40, 78, 88]`

Write a program that:
1. Iterates through the list
2. Counts how many students meet the attendance requirement (≥ 75%)
3. Counts how many do not

**Concepts Tested:**
- Loops
- Counters
- Conditional logic inside loops

---

### Problem 4: Scholarship Eligibility System (Advanced)

A scholarship is awarded based on the following rules:
- CGPA ≥ 3.5
- Family income ≤ 80,000 PKR

Given two lists:
- CGPAs of students
- Monthly family incomes

Write a program that:
1. Iterates through student records
2. Determines scholarship eligibility using compound conditions
3. Counts the total number of eligible students

**Concepts Tested:**
- Compound conditions (`and`)
- Loop + decision integration
- Real-world rule modeling

---

### Problem 5 (Bonus): Sensor Alert System

A monitoring system records sensor values.

Given a list of readings:
1. Identify readings outside the safe range (20–80)
2. Count total alerts
3. Calculate the percentage of alert readings

**Concepts Tested:**
- Accumulators
- Analytical thinking
- Output interpretation
