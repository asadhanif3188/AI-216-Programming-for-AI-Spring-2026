**Semester:** Spring 2026  
**Credits:** 2 (Lecture) + 1 (Lab)

## 1. Why this course exists (the “Programming for AI” mindset)

In AI work, programming is not only about writing correct syntax. It is about building *repeatable workflows*:

**Data → Cleaning → Exploration → Features → Model → Evaluation → Iteration**

This course will build your programming foundations and then immediately connect them to the kinds of tasks you will do in AI and ML projects.

---

## 2. Week 1 learning outcomes

By the end of Week 1, you should be able to:

1. Explain how programming supports Machine Learning, Data Science, and AI Engineer roles.  
2. Identify the core tools used in AI workflows (Python + IDE, GitHub, Kaggle, LinkedIn as a professional tool).  
3. Read real AI/ML job postings and extract skill requirements and expectations.  
4. Complete the Week 1 lab setup and publish your first Python script to GitHub.

## 9. Quick glossary (Week 1)

- **IDE:** software where you write/debug code (e.g., VS Code)  
- **Version control:** tracks changes so you can revert, collaborate, and audit work  
- **Repository (repo):** project folder tracked by Git/GitHub  
- **Commit:** a saved snapshot of your work history  
- **Dataset:** structured data used for analysis/ML training and evaluation
